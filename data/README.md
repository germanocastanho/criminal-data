# Criminal Data 🔎

This project uses the occurrence records ("Ocorrências") from October 2021 to August
2026, published on the [SSP/RS Open Data Page](https://www.ssp.rs.gov.br/dados-abertos)
by the Public Security Secretariat of Rio Grande do Sul, Brazil. The yearly CSVs (not
versioned) were downloaded, unzipped, and saved as `data/<year>_raw.csv`.
